# theGamo 🎴

**theGamo** is the online web version of the popular card game **The Game**. Play with your friends directly from your browser and test your teamwork and strategy skills!

---

## Features

- **Multiplayer only** – cooperate with friends to beat the game
- **Responsive design** – works on desktop and mobile
- Built with **Nuxt.js** for a modern, fast web experience
- Easy deployment using **Docker**

## Getting Started

Follow these steps to run **theGamo** locally or on your server.

### Clone the repository

```bash
# Clone the repo
git clone https://github.com/yourusername/theGamo.git

# Build and run Docker container
$ sudo docker build -t nuxt-app .
$ sudo docker run -d --name nuxt-app   -p 3000:3000   --restart=always   nuxt-app
```
